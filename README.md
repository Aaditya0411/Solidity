# Solidity Smart Contracts Practice 🚀

This repository contains my Solidity practice programs created while learning Ethereum Smart Contract Development and Blockchain fundamentals.

## 📂 Smart Contracts Included

### 1. SimpleStorage.sol
Stores and retrieves a favorite number.
- State Variables
- Functions
- Public Visibility
- View Functions

### 2. BasicSimpleStorage.sol
Demonstrates Solidity basic data types.
- bool
- uint
- int
- string
- address
- bytes32

### 3. state.sol
Demonstrates State Variables and different methods of assigning values.
- Constructor Initialization
- State Variables
- Setter Functions

### 4. local.sol
Demonstrates Local Variables inside functions.
- Function Scope
- Memory Variables

### 5. gettersetter.sol
Example of Getter and Setter functions.
- Read Data
- Update Data
- State Modification

### 6. constructor.sol
Demonstrates Constructor usage.
- Parameterized Constructor
- Contract Initialization

### 7. if-else.sol
Demonstrates conditional statements.
- if
- else if
- else

### 8. Loop.sol
Demonstrates looping concepts.
- while loop
- Array Traversal

### 9. Array.sol
Demonstrates Fixed Size Arrays.
- Array Declaration
- Array Update by Index

### 10. DynamicArray.sol
Demonstrates Dynamic Arrays.
- push()
- pop()
- length

### 11. identity.sol
Simple identity management contract.
- Constructor
- String Storage
- Age Management
- Getter Functions

### 12. structure.sol
Starter file for learning Solidity Structures (Structs).
